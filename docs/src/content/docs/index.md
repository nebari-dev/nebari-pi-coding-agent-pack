:::caution[Experimental]
The Pi Coding Agent Pack — and this documentation site — is **experimental**.
Interfaces, configuration, and behavior may change without notice.
:::

The Pi Coding Agent Pack extends Nebari's data-science JupyterHub stack with a
[Pi](https://www.npmjs.com/package/@mariozechner/pi-coding-agent) coding-agent workflow: a launcher
service in the Hub, named-server profiles, and a browser terminal for working
with the Pi CLI on the cluster.
